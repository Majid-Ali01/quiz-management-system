## 📌 Project Overview

**Quiz Management System** is a desktop-based Java application developed as a **2nd Semester Final Project**.

The system provides an interactive platform for conducting quizzes, managing questions, recording scores, and maintaining quiz history through a **MySQL relational database**.

The project demonstrates practical implementation of:

- Object-Oriented Programming
- Java Swing GUI development
- JDBC database connectivity
- MySQL database management
- SQL queries
- Prepared Statements
- SHA-256 password hashing
- Abstract classes
- Interfaces
- Inheritance
- Polymorphism
- Exception handling
- DAO-based database operations

The application is designed with separate **Admin** and **User** workflows to provide a clear and structured quiz experience.

---

## ✨ Features

### 👨‍💼 Admin Module

- 🔐 Admin authentication
- ➕ Add new quiz questions
- 🏷️ Create and manage quiz topics
- 📝 Add multiple-choice questions
- ✅ Define correct answers
- 🔒 Password verification with SHA-256 support

### 👨‍🎓 User Module

- 👤 Enter user name
- 📚 Select quiz topic
- ▶️ Start quiz
- 🔘 Answer multiple-choice questions
- 🧮 Automatic score calculation
- 🏆 Display final score

### 📊 Quiz History

- 📋 View previous quiz attempts
- 🔎 Search history by username or topic
- 🗑️ Clear quiz history
- 💾 Store quiz results in MySQL

### 🗄️ Database Integration

The application uses MySQL to store:

- Admin credentials
- Quiz topics
- Questions
- Quiz history

JDBC provides communication between the Java application and MySQL database.
